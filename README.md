# Oesophageal Therapy Fellowship – Year Plan

Offline phone app (PWA) for a one-year oesophageal endoscopic therapy fellowship, based on the 2026 ESGE position statement (Weusten et al., doi:10.1055/a-2948-4729) and European ESD training guidance.

**Install:** open https://sebastiz.github.io/oesophageal-fellowship/ on your phone, then
- iPhone (Safari): Share → Add to Home Screen
- Android (Chrome): menu → Install app

Progress is saved on the device only and works without a connection. Use **Download backup** regularly and **Share with supervisor** to send progress.
